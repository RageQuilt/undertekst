      1. Phone and TV on the same Wi-Fi.

      2. On the TV: Settings → General (or Connection) → Network → Network Status → IP Settings. Type the IP address below.

      3. Tap "Open TV security page", then Advanced → Proceed. It's a one-time step that lets this app talk to the TV. A blank page or error text after that is fine; come back here.

      4. Tap Connect and choose Allow on the TV.
